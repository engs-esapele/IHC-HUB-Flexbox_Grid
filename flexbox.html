Flexbox

Flexbox é um modelo de layout do CSS que organiza elementos: em uma linha ou em uma coluna. Ele facilita o alinhamento e a distribuição dos itens, inclusive quando o tamanho da tela muda.

Para ativar o Flexbox em um contêiner, use display: flex;. Os elementos filhos passam a ser chamados de itens flexíveis.

Principais propriedades

  • display: flex; — ativa o Flexbox no contêiner.
  • flex-direction — define a direção dos itens: linha (row) ou coluna (column).
  • justify-content — distribui os itens no eixo horizontal, como no início, no centro ou com espaço entre eles.
  • align-items — alinha os itens no eixo vertical.
  • flex-wrap — permite que os itens passem para outra linha quando não há espaço suficiente.
  • gap — define o espaço entre os itens.
  • flex — controla como um item cresce ou encolhe para ocupar o espaço disponível.
  • align-content — distribui as linhas quando há várias linhas e espaço extra no eixo transversal.

Exemplo

Neste exemplo, display: flex coloca as caixas lado a lado, justify-content: space-around distribui o espaço e gap cria uma distância entre elas.

.container {
  display: flex;
  justify-content: space-around;
  align-items: center;
  gap: 12px;
}

Eixos do Flexbox

O eixo principal acompanha a direção definida em flex-direction. O eixo transversal fica perpendicular ao principal. Ao mudar de row para column, a direção usada por justify-content também muda.

Experimente alterar estes valores no CSS e observe como as caixas se reorganizam:

  • flex-direction: column; — empilha os itens.
  • justify-content: center; — centraliza no eixo principal.
  • align-items: flex-end; — alinha no final do eixo transversal.
  • flex-wrap: nowrap; — impede a quebra para outra linha.
  • gap: 24px; — aumenta o espaço entre os itens.
