O que é CSS Grid?

O CSS Grid é um sistema de layout bidimensional: organiza elementos em linhas e colunas. Ele é útil para criar galerias, painéis e páginas que se adaptam a diferentes tamanhos de tela.

As principais propriedades são:

  • display: grid; — ativa o Grid no elemento contêiner.
  • grid-template-columns — define as colunas e seus tamanhos.
  • grid-template-rows — define as linhas e seus tamanhos.
  • gap — define o espaço entre linhas e colunas.
  • grid-column — define em quais colunas um item se posiciona ou se estende.
  • grid-row — define em quais linhas um item se posiciona ou se estende.
  • justify-items e align-items — alinham os itens dentro de suas células.

.grid-demo {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

repeat(3, 1fr) cria três colunas de mesma largura. A unidade fr divide o espaço disponível em frações.

Listas em HTML

As listas agrupam informações relacionadas. Existem três tipos comuns:

Lista não ordenada

Usa ul para criar a lista e li que define um item dentro de uma lista. Os itens aparecem com marcadores.

  • HTML
  • CSS
  • JavaScript

Lista ordenada

Usa olpara criar a lista e li. Os itens aparecem numerados.

  1. Criar o HTML
  2. Estilizar com CSS
  3. Testar a página

Lista de descrição

Usa dl que cria a lista, dt para o termo que será descrito e dd para suas descrições.

HTML
Define a estrutura da página.
CSS
Controla a aparência da página.

Principais propriedades CSS para listas

  • list-style-type — muda o marcador, como disc, circle, square ou decimal.
  • list-style-image — permite usar uma imagem como marcador.
ul {
  list-style-type: square;
  list-style-position: inside;
  padding-left: 12px;
}

ol {
  list-style-type: decimal;
}
